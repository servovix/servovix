# Política de segurança

Este repositório contém o site institucional estático da **ServoVIX**
(https://servovix.com.br), publicado pelo GitHub Pages.

## Escopo

O site é composto apenas por HTML, CSS, JavaScript e imagens estáticas.
Não há backend, banco de dados, autenticação ou processamento de pagamentos.

O formulário de orçamento **não envia dados para nenhum servidor**: ele monta
uma mensagem de texto e a abre no WhatsApp do próprio visitante. Nenhuma
informação preenchida é armazenada por este site.

## Como reportar uma vulnerabilidade

Se você encontrar um problema de segurança — por exemplo, conteúdo injetado,
link malicioso, comprometimento do domínio ou da publicação — entre em contato:

- **E-mail:** servovix@gmail.com
- **WhatsApp:** (27) 99843-2920

Inclua, se possível:

1. a URL afetada;
2. a descrição do problema e como reproduzi-lo;
3. o impacto esperado.

Pedimos que **não divulgue publicamente** a falha antes do contato e de um
prazo razoável para correção.

## Retorno

O recebimento é confirmado assim que possível e o andamento é informado ao
longo da análise. Relatos válidos são corrigidos com prioridade; relatos fora
do escopo acima recebem uma resposta explicando o motivo.

## Fora do escopo

- Ausência de cabeçalhos de segurança que dependem do GitHub Pages.
- Resultados de varredura automatizada sem impacto demonstrável.
- Práticas recomendadas sem vulnerabilidade associada.
